## Problem Statement
This is a web-based Favourite Subject Poll application.
Users can select their favourite subject from a list and submit their vote.
The application stores and displays the voting results using Java Servlets.

---

## Technologies Used
- Java (Servlets)
- HTML
- CSS
- Apache Tomcat 10
- Eclipse IDE

---

## How to Run This Project
1. Import project into Eclipse as Dynamic Web Project
2. Configure Apache Tomcat server
3. Run project on server
4. Open browser and go to:
   http://localhost:8080/FavouriteSubjectPoll/

---

## Output
- Input form page where user selects subject
- Result page showing vote count or selection result
